Draft a post

Draft posts here. To publish live, use GitHub Actions (below)—no API keys in the browser. You can also Generate code and paste into content.js locally. This page is not linked from the public blog.

Letters, numbers, hyphens. Used in post.html#your-slug

Publish live (GitHub only)

On GitHub open Actions → Publish blog post → Run workflow. Fill title, slug, date, excerpt, and the other fields to match this form. For Body (base64), click Copy body as UTF-8 Base64 below (uses your Article HTML field). That commits to main; the site redeploys automatically.

Paste this into content.js

1. Open content.js in your editor.
2. Add a comma after the previous post’s closing }, if needed.
3. Paste the block below inside BLOG_POSTS = [ ... ].
4. Optional: add the slug to popularSlugs.
5. Commit and push (or save) to publish.
